# 变更记录（CHANGELOG）

记录 v1.1 需求说明之后的产品与工程变更。需求基线见 [`AI大学生个性化学习助手-功能需求说明-v1.1.md`](AI大学生个性化学习助手-功能需求说明-v1.1.md)。

## v1.3 — 2026-10-20

### 部署支持

- 新增 `start.sh` / `stop.sh`：Linux / macOS 下 `bash start.sh` 后台启动（日志写 `data/server.log`，检查 Node ≥ 18、避免重复启动）、`bash stop.sh` 按 pid 停止。两个脚本保持 LF 换行。
- `scripts/pack.ps1` 增加 `-Server` 模式，输出 `学伴AI-服务器版.zip`（保留 API 密钥）；该模式的 `使用说明.txt` 附服务器部署步骤与 systemd 托管示例。
- **修复打包产物在 Linux 上解压异常**：Windows PowerShell（`Compress-Archive` 与 .NET Framework 的 `ZipFile.CreateFromDirectory`）用反斜杠作为 zip 条目分隔符，Linux 解压会得到一个带反斜杠的怪文件名而不是目录。改为逐条写入 zip 并强制使用正斜杠；`使用说明.txt` 改为无 BOM 的 UTF-8。

### 更名

- 项目定名 **“学伴AI”大学生个性化学习助手**（此前工作名称为「AI 大学生个性化学习助手」）。同步更新范围：浏览器标题、登录页主标题、侧边栏品牌名（`学伴AI` / 个性化学习助手）、四个一键脚本的横幅与防火墙规则名、打包脚本的包名、README 主标题、v1.1 需求说明标题。
- 需求说明文件名保持 `AI大学生个性化学习助手-功能需求说明-v1.1.md` 不变，避免历史链接失效；文档内部标题已改为新名字。

## v1.2 — 2026-10-20

### 导航与信息架构

- **「学习资料与计划」提升为一级页面，改名「学习资料分析」**，位于侧栏第二项（今日之后），并在移动端底部导航中作为「资料」出现。
  - 路由由 `#/me/docs` 调整为 `#/docs`，详情页为 `#/docs/:id`；旧地址自动跳转，历史链接与书签不失效。
  - 「我的 → 我的学习」不再重复列出该入口（其统计信息已由一级页面承载）。
  - 说明：v1.1 需求说明中 F-08 原挂在「我的」之下，本次按评审反馈上移；其余能力与交互不变。

### 交互细节

- 登录页输入框不再显示占位提示（字符数等规则改为提交时提示）。
- 密码框新增显示 / 隐藏按钮：切换 `password` / `text`，同步图标与无障碍标签，切换后焦点回到输入框；回车提交时忽略按钮焦点，避免误触。
- 资源搜索推送页改为渐进渲染：先出页面骨架（对话记录 + 「正在为你挑选…」），推荐结果返回后只刷新推荐区，不再整页等待。
- **资源搜索推送页的 AI 检索区改版**（原「找资源」在页面下半部分、只有一个单行输入框，不凸显）：
  - 位置提到页面最上方，下方紧跟对话记录（无记录时不占空间），推荐卡片移到其后；
  - 标题改为「让 AI 按你的需求找资源」，并配搜索图标与品牌浅色底，和推荐卡片明显区分；
  - 输入框上方一句说明「说出主题、基础水平和偏好的资源形式」；
  - 单行输入改为 3 行多行输入框（可纵向拖拽、Enter 发送 / Shift+Enter 换行、输入法组词时的回车不误发）；
  - 「发送」改为横向主按钮「AI 搜索资源」，带图标与「正在找…」状态；
  - 提供三个可点示例词（找二叉树遍历视频 / 推荐递归练习题 / 找适合零基础的排序课程），点击即检索。
  - 顺带修掉卡片类型标签（网课 / 文档等）在窄列里被挤成竖排的问题。
- **AI 检索拆分为独立模块「AI 找资源」**：原先与自动推送同页，现侧边栏新增第五项「AI 找资源」（移动端底部导航「找资源」），承载多行输入、示例词、检索结果与检索记录；「资源搜索推送」只保留自动推送与「换一批」，两页头部互相提供入口（「AI 找资源」↔「看推荐」）。
  - 两页共用同一套资源卡片渲染与收藏/打开/不感兴趣逻辑，避免重复实现。
- **资源卡片精简**：去掉卡片里那块紫底的推荐理由，卡面只保留「名称 + 类型 / 一句话简介 / 平台 + 价格 + 主题 + 核验状态 / 适合人群 / 操作按钮」，减少视觉噪音；「不感兴趣」按钮保留。数据与提示词未变（接口仍会返回 `reason` 字段），后续要恢复展示只需重新渲染该字段。

> 说明：本条与 v1.1 需求说明中 F-05「每张卡片附推荐理由」不一致，属于按评审反馈做的产品取舍，理由字段仍保留在数据里。

### 工程与测试

- 服务启动时载入 `.env`（优先级：系统环境变量 > `.env` > `config.local.json` > 默认值），密钥只走环境变量；未配置时日志给出明确提示。
- 浏览器检查（`test/ui.js`）扩展到 20 个页面，并新增断言：登录框无占位提示、密码显示切换、底部导航 5 项、旧地址 `#/me/docs` 可正常跳转。

### 修复

- **搜题统计页柱状图文字被横向拉伸**：原因是 SVG 以 `viewBox="0 0 100 176"` 配 `preserveAspectRatio="none"` 铺满卡片，横向放大约 9.5 倍而纵向不变，文字与柱形一起变形。改为 flex + 固定高度的真元素柱状图（柱高按像素比例、柱宽上限 52px、标签为普通文本并自动省略），文字不再参与缩放；同时把「难度分布」下方预留的空卡片改为仅下钻后出现。
- **「不含密钥」便携包可能仍带密钥**：打包前处理只清空了 `config.local.json`，若使用者按 README 把密钥写在 `.env` 里，`.env` 会原样进入包内。现在两处都会清空，并在打包后自检是否残留 `sk-` 形式的密钥；同时把两种包改成不同文件名（`…便携版.zip` / `…便携版-不含密钥.zip`），避免误发。
- **推荐资源名可能带粗俗字样**：在资源检索与常态推荐的提示词中加入命名约束（不清爽的资源不推荐，必要时改用中文别名），避免演示时出现带脏话的开源仓库名。
- **崩溃信息看不到**：启动脚本以隐藏窗口运行，异常栈会丢在子进程的 stderr 里。服务现在把未捕获异常与未处理的 Promise 拒绝统一写入 `data/server.log`。
- **地址列表出现代理伪地址**：Clash 等代理的 fake-ip 占用了保留网段 198.18.0.0/15，服务启动横幅与「查看地址」都会列出 `198.18.0.x`。脚本与服务端的内网地址枚举都已跳过该网段。
- **窄屏页头按钮被挤成竖排**：页面标题旁的多个按钮在手机宽度下换成竖排文字。现在页头允许换行、按钮内文字不折行。

### 移除

- 移除两个一键打包脚本（`打包便携版.bat`、`打包便携版-不含密钥.bat`）：跨机交付以 GitHub 仓库为主，便携包不再是常规流程。打包能力保留在命令行 `scripts/pack.ps1 [-WithoutKey]`，需要时仍可生成，并沿用上面的密钥清理与自检逻辑。
