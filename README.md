# AI 大学生个性化学习助手

> 基于**知识障碍识别**与**动态计划调整**的大学生个性化学习助手 —— 上传课程资料，得到可执行的学习计划、有过程的 AI 讲解，以及会随学习证据自动调整的安排。

[功能一览](#2-功能一览) · [技术架构](#3-技术架构) · [快速开始](#5-快速开始) · [配置](#6-配置说明) · [接口](#7-接口一览) · [测试](#9-测试) · [部署](#10-部署)

## 1. 项目简介

### 1.1 要解决的问题

大学生用 AI 学习时，常见的三个断点：

1. **「给了通用答案，但没解决我的卡点」** —— 大模型的回答往往从零讲起，或者只给结论，学生不知道自己卡在哪一步。
2. **「计划写得很漂亮，第二天就废了」** —— 计划是一次性生成的，不随真实进度、可用时间、练习结果变化。
3. **「资源一大堆，不知道哪个该看」** —— 资源分散在各平台，缺少与当前学习任务对应的入口。

### 1.2 核心闭环

```
上传课程资料 ──► 结构化成「学习地图」 ──► 生成每日可执行任务
      ▲              （章节/知识点/先修关系/难点/自测题）        │
      │                                                        ▼
      └──── 计划自动重排 ◄── 学习证据（完成/练习/理解反馈） ◄── 任务驱动的 AI 辅导
```

四个环节共享同一组结构化学习数据：**资料分析**给出知识结构，**计划**把它变成任务，**辅导**在任务上下文里讲题，**成长记录**把证据回写成计划的重排依据。

### 1.3 明确的边界（有意不做的事）

| 不做 | 原因 |
|---|---|
| 能力评分、等级、排行榜 | 把学习行为变成对人的评价，会让学生不敢用 |
| 「X 天精通」类效果承诺 | 无法负责，且会误导 |
| 跨学生题库、题目共享、热门题排行 | 版权与隐私，也让 AI 退化成搜题库 |
| 把主观自述当成难度或能力依据 | 自述只能作背景语境，不能变成结论 |
| 存储/转存/下载第三方资源文件 | 平台只保存链接与元信息，不成为分发渠道 |

## 2. 功能一览

| 模块 | 能力 |
|---|---|
| **今日** | 每天一条可马上开始的学习建议（已经学了 / 今天休息 / 不想学这个）；今日任务（开始学习 / 已完成 / 暂时做不到 / 需要帮助）；休息日不排任务，逾期可一键顺延 |
| **学习资料分析**（侧栏第二项） | 上传 PDF / TXT / DOCX / MD → 章节摘要、知识点、先修关系、难点（附判定原因）、自测题 → 按每日可用时长生成计划，任务可调整、可重排、可导出 |
| **AI 搜题** | 文字或拍照提问（图像走原生多模态，不引入 OCR）；识别结果先给学生核对；固定结构解答（题目理解 → 知识点 → 思路 → 逐步推导 → 结论与检验 → 易错提示）；追问；标注可修正；搜题历史与统计（柱状图 + 下钻） |
| **资源搜索推送** | 对话式检索 + 常态推荐（附推荐理由、换一批、不感兴趣）；卡片内收藏；链接可用性核验 |
| **我的 · 基本信息** | 院校 / 专业（三级目录 + 自填兜底）/ 学期与学制；学习目标；每周可用时间与休息日 |
| **我的 · 院校与专业资料** | 自填名称的后台核对与规范化，逐条标注「已核实 / 待核实」，可纠错重核 |
| **我的 · 我的学习情况** | 自由文本 → AI 提炼为结构化条目，严格区分**客观陈述**与**主观自述**（自述永远标注「非能力判定」） |
| **我的 · 成长记录** | 学习记录与知识点「证据状态」（未诊断 / 待学习 / 学习中 / 需复习 / 有近期正确表现），驱动计划重排，不影响讲解难度 |
| **我的 · 资源库** | 收藏夹：标签、排序、打开计数、失效反馈 |
| **我的 · 每日建议记录** | 历史建议与回应，可撤回 |
| **我的 · 数据与隐私** | 「平台记录了我什么」说明、分类清除、全部清除、JSON 导出 |
| **工程化** | 一键启动 / 关闭 / 查看地址 / 打包便携版（Windows），全部零依赖 |

## 3. 技术架构

### 3.1 技术选型

| 层 | 选择 | 理由 |
|---|---|---|
| 运行时 | **Node.js 18+（零第三方依赖）** | 只用内置模块即有 HTTP、加密、压缩、文件能力；PDF/DOCX 解析、JSON 存储、密码哈希全部手写。评审拿到代码可直接 `node server.js` 运行，不需要 `npm install`，也不受依赖版本漂移影响 |
| 后端 | 内置 `http` + 自建路由表 | 55 个接口用一张表声明式注册，`METHOD /path` 字符串直接映射到处理函数 |
| 前端 | 原生 HTML/CSS/JS（无构建） | 三人小团队维护成本最低；调试即刷新；图表用 SVG 手绘，避免引入图表库 |
| 存储 | 单文件 JSON（`app/data/db.json`） | 演示与评审场景可读、可备份、可手工核对；写入采用「临时文件 + 重命名」原子替换 |
| 模型 | **DeepSeek（默认 `deepseek-flash`）**，后端可配置切换 | 原生支持图像输入，因此**不需要 OCR 组件**；模型名、地址、超时全部走配置，代码里没有写死 |

### 3.2 分层结构

```
┌──────────────────────────── 浏览器（app/public）────────────────────────────┐
│ index.html + style.css + core.js（路由/接口/组件）                           │
│ pages-today.js（今日、搜题）  pages-more.js（资源、我的及全部子页）           │
└───────────────────────────────────┬──────────────────────────────────────────┘
                                    │ fetch（全部相对路径，换 IP/域名无需改代码）
┌───────────────────────────────────▼──────────────────────────────────────────┐
│ app/server.js   静态资源 + 会话 Cookie + JSON 请求体 + multipart 上传        │
│ app/routes.js   「METHOD /path」→ handler 路由表（支持 :param）              │
├──────────────────────────────────────────────────────────────────────────────┤
│ app/lib/api/*   领域模块：auth / profile / selfreport / solve / resources /  │
│                 docs / tasks / me —— 每个模块只依赖 util 与下层能力           │
│ app/lib/api/util.js  画像摘要、主题归一、资源链接构造、日期与工作日计算       │
├──────────────────────────────────────────────────────────────────────────────┤
│ app/lib/ai.js      模型接入层：可配置、超时、有限重试、结构化输出校验、       │
│                    截断 JSON 抢救、调用日志（不记录密钥）                     │
│ app/lib/prompts.js 全部提示词与全局约束（禁止能力定性/效果承诺/焦虑表述/注入）│
│ app/lib/parse.js   PDF 文本流解析、DOCX（zip+XML）解析、格式与体积校验        │
│ app/lib/store.js   集合式 JSON 存储：insert/find/update/remove + 原子落盘     │
│ app/lib/auth.js    scrypt 密码哈希、会话令牌、按 user_id 的数据隔离          │
│ app/lib/scheduler.js 任务排期：按每日容量、休息日、缓冲计算日期               │
│ app/lib/seed.js    院校库、专业三级目录、主题别名表                          │
│ app/workers.js     异步任务：院校专业核查、自述提炼、资料解析、推荐、链接核验 │
└──────────────────────────────────────────────────────────────────────────────┘
```

### 3.4 关键设计决策

| 决策 | 做法 | 目的 |
|---|---|---|
| 结构化优先 | 需要程序消费的输出一律要求 JSON，服务端校验后才入库 | 避免把模型散文写进数据库 |
| 长输出容错 | 提高 `max_tokens` + 截断 JSON 自动补齐 + 失败重试 | 推理型模型容易吃满预算，防止整次调用白费 |
| 规则与模型分工 | 日期、容量、休息日、状态流转由后端规则算；模型只给内容与解释 | 计划可验证、可复现 |
| 链接白名单 | 模型只能给「平台 + 关键词」，URL 由后端按平台检索模板拼出 | 杜绝死链与臆造资源 |
| 图像直连多模态 | 图片直接作为 `image_url` 送入模型，不做 OCR | 少一层组件，公式与版式识别更稳 |
| 数据隔离 | 所有查询以登录用户 `user_id` 为条件；素材/记忆/记录按人隔离 | 满足隐私要求，避免越权取数 |
| 不施压 | 无红点、无连续天数、无排行；休息与未完成不产生负面记录 | 产品价值观，也是长期可用的前提 |

## 4. 环境要求

| 项目 | 要求 |
|---|---|
| Node.js | **18 或更高**（使用内置 `fetch`；推荐 20 LTS）。启动脚本会检查版本并提示下载地址 |
| 第三方依赖 | **无**。不需要 `npm install` |
| 浏览器 | 任意现代浏览器（Chrome / Edge / Firefox / Safari） |
| 磁盘 | 约 200 MB（含运行数据与上传文件） |
| 网络 | 调用模型 API 需要联网；离线时其余功能仍可浏览，AI 相关操作会给出明确提示 |
| 系统 | Windows（提供一键 `.bat` 与 `.ps1` 脚本）；macOS / Linux 用命令行 `node server.js` 亦可运行 |

### 4.1 依赖清单

**运行时依赖：0 个 npm 包。** 没有 `package.json`、没有 `node_modules`，不执行 `npm install`。所有能力均使用 Node.js 内置模块实现：

| 内置模块 | 用途 |
|---|---|
| `http` | HTTP 服务、静态资源、API 路由与请求体解析（含 multipart 上传） |
| `fs` / `path` / `os` | 文件读写、路径处理、网卡地址枚举（启动时打印访问地址） |
| `crypto` | 密码 `scrypt` 哈希、会话令牌生成、`timingSafeEqual` 恒定时间比较 |
| `zlib` | 解压 PDF 内容流与 DOCX（zip）条目 |
| 全局 `fetch` / `AbortController` | 调用模型 API 与资源链接可用性核验（Node 18+ 内置） |

| 开发/测试期额外需要 | 说明 |
|---|---|
| 任意现代浏览器 | 手动验收 |
| Microsoft Edge + `--remote-debugging-port=9222` | 仅在执行 `test/ui.js`（浏览器渲染检查）时需要，通过 CDP 驱动 |

## 5. 快速开始

### 5.1 Windows 一键启动

1. 安装 Node.js 18+（[下载](https://nodejs.org/zh-cn/download)）
2. 复制 `.env.example` 为 `app/.env`，填入 `AI_API_KEY`
3. 双击 `app\启动.bat`，浏览器会自动打开 `http://127.0.0.1:8899`

| 脚本 | 作用 |
|---|---|
| `启动.bat` | 局域网模式启动，自动识别当前 IP 并打印访问地址 |
| `启动-服务器.bat` | 部署在公网服务器时用：启动后自动探测并突出显示公网访问地址 |
| `启动-仅本机.bat` | 只允许本机访问 |
| `查看地址.bat` | IP 变化后查看最新地址（不重启服务） |
| `关闭.bat` | 只结束占用本项目端口的进程，不影响其它程序 |
| `打包便携版-不含密钥.bat` | **对外交付用**：生成 `AI学习助手-便携版-不含密钥.zip`，清空 `config.local.json` 与 `.env` 里的密钥、会话与运行痕迹，收到的人自己填密钥 |
| `打包便携版.bat` | **仅自用**：生成 `AI学习助手-便携版.zip`，保留密钥，适合在自己可信设备间搬运；不要发给他人 |

### 5.2 命令行启动（任意平台）

```bash
cd app
cp ../.env.example .env      # 填入 AI_API_KEY
node server.js
```

默认监听 `0.0.0.0:8899`，本机访问 <http://127.0.0.1:8899>。

### 5.3 首次使用

- 打开首页 → 点「注册」创建账号 → 按引导填写院校 / 专业 / 学期 → 设定学习目标与每周可用时间 → 可选填写学习情况。
- 想直接看有数据的效果：先配置好 `AI_API_KEY`，然后执行
  ```bash
  node test/seed-demo.js      # 生成演示账号 demo / demo123456 与一份示例资料、计划、记录
  ```

## 6. 配置说明

### 6.1 环境变量（推荐方式）

复制 `.env.example` 为 `app/.env`（已被 `.gitignore` 忽略）：

| 变量 | 必填 | 默认值 | 说明 |
|---|---|---|---|
| `AI_API_KEY` | **是** | 空 | 模型服务的 API Key，仅存于本机 `.env` 或系统环境变量 |
| `AI_BASE_URL` | 否 | `https://api.deepseek.com` | 兼容 OpenAI 协议的服务地址 |
| `AI_MODEL` | 否 | `deepseek-flash` | 文本模型 |
| `AI_VISION_MODEL` | 否 | 同 `AI_MODEL` | 图像识别模型（需支持多模态输入） |
| `AI_PROVIDER` | 否 | `deepseek` | 仅用于日志标识 |
| `AI_TIMEOUT_MS` | 否 | `120000` | 单次调用超时 |
| `HOST` | 否 | `0.0.0.0` | 监听地址；仅本机用 `127.0.0.1` |
| `PORT` | 否 | `8899` | 监听端口 |
| `PUBLIC_URL` | 否 | 空 | 绑定域名或反向代理时的对外地址，启动脚本优先显示 |

优先级：**系统环境变量 > `app/.env` > `app/config.local.json` > 内置默认值**。

### 6.2 配置文件（可选）

`app/config.local.json` 用于不放环境变量的场景（已被 `.gitignore` 忽略），字段见 [`app/config.example.json`](app/config.example.json)。其中的 `apiKey` 留空即可，用 `.env` 提供密钥更安全。

### 6.3 密钥与敏感信息处理

- 仓库内**不包含任何真实密钥**：`.env`、`config.local.json`、运行数据、日志、打包产物均在 `.gitignore` 中。
- 服务端日志只记录用途、模型名、耗时与状态，不记录密钥。
- 密钥泄露时的处理：在服务商控制台吊销旧 Key → 生成新 Key → 更新本机 `.env` → 重启服务（无需改代码）。

## 7. 接口一览

统一前缀 `/api`，除注册/登录/健康探测外均需会话 Cookie（`sid`），所有查询以当前用户为条件。

| 分组 | 接口（节选） |
|---|---|
| 账号 | `POST /auth/register`、`POST /auth/login`、`POST /auth/logout`、`GET /auth/me` |
| 画像 | `GET|PUT /profile`、`GET /presets/schools`、`GET /presets/majors`、`GET /presets/majors/tree`、`GET|POST|PATCH|DELETE /goals`、`GET|PUT /time-constraint` |
| 院校专业资料 | `GET|POST /school-major-profile`、`POST /school-major-profile/:id/feedback`、`POST /school-major-profile/:id/reverify` |
| 学习情况 | `GET|POST|DELETE /self-report`、`PATCH|DELETE /self-report/items/:id`、`POST /self-report/re-extract` |
| 搜题 | `POST /solve`、`POST /solve/image-extract`、`POST /solve/:id/followup`、`GET /solve/history`、`GET /solve/stats`、`PATCH /solve/:id/annotation`、`DELETE /solve/:id` |
| 自测题 | `POST /diagnostic`、`GET /diagnostic/:id` |
| 资源 | `GET /resources/recommend`、`POST /resources/dialog`、`POST /resources/:id/bookmark|open|report|not-interested`、`GET /bookmarks`、`PATCH|DELETE /bookmarks/:id` |
| 资料与计划 | `POST|GET /documents`、`GET /documents/:id`、`POST /documents/:id/analyze`、`GET /documents/:id/file`、`POST /plans`、`GET /plans/:id`、`POST /plans/:id/reschedule`、`GET /plans/:id/export` |
| 任务与记录 | `GET /today`、`GET|POST /tasks`、`PATCH /tasks/:id`、`GET|POST /records`、`GET /knowledge-states`、`GET|POST /suggestions/...` |
| 隐私 | `GET /privacy/data-map`、`POST /privacy/purge`、`GET /privacy/export` |

接口返回统一为 JSON；错误返回 `{ "error": "可读的中文原因" }` 与相应状态码（400 参数、401 未登录、404 不存在、500 内部错误）。

## 8. 数据存储与备份

| 内容 | 位置 | 说明 |
|---|---|---|
| 业务数据 | `app/data/db.json` | 集合式 JSON：用户、画像、资料、计划、任务、记录、资源、建议、调用日志等 |

## 10. 部署

| 场景 | 做法 |
|---|---|
| 本机演示 | 双击 `app\启动.bat` |
| 局域网（手机 / 其他电脑） | 双击 `app\启动.bat`，用打印出的局域网地址；首次需放行防火墙端口 |
| 公网服务器 | 双击 `app\启动-服务器.bat`，脚本自动探测公网 IP 并打印对外地址；需在云厂商安全组放行端口 |
| 域名 / 反向代理 | 在 `.env` 里设置 `PUBLIC_URL=https://your.domain`，启动脚本优先显示它 |

> 公网可访问意味着任何知道地址的人都能打开且可注册。演示结束后请关闭端口，或改为「启动-仅本机.bat」+ SSH 隧道。
